# Project licensing status

The owner has not selected a project-wide license. This package does not add a new license grant or claim to be open source. Public visibility is not a substitute for a license.

Before describing a public release as open source, the owner must select suitable terms for their original code and documentation and review applicable third-party notices. Do not assume that licensing original code grants rights to Pathfinder rules text, trademarks, purchased adventures, maps or other assets. No Adventure Path artwork or PDFs are bundled.

Dependency packages keep their own licenses. Their notices are included with the downloadable dependencies and indexed in THIRD_PARTY_NOTICES.md. The icon was generated for this project; no third-party game logo was deliberately supplied as an asset.

GitHub guidance: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository
